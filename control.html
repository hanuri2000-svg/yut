도랑배 윷놀이 조작화면
빈 16강 칸을 눌러 팀을 선택해. 16팀을 모두 넣으면 시작할 수 있어.
v1.0.6
사용 방법
① 팀 명단: 필요하면 팀 명단 수정에서 16개 팀 이름 변경
② 대진 설정: 시작 전 빈 16강 칸을 클릭 → 팀 선택 → 16팀 모두 배치
③ 경기 시작: 16팀 배치 후 시작 버튼 클릭
④ 승자 표시: 경기 종료 후 대진표에서 이긴 팀 이름을 클릭 → 다음 라운드 자동 진출
⑤ 잘못 눌렀으면 직전 결과 취소 사용
